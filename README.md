# 🧩 Algorithm 문제 풀이 기록

SWEA, 프로그래머스, 코드트리에서 푼 문제들을 기록하는 저장소입니다.

[백준허브(BaekjoonHub)](https://chromewebstore.google.com/detail/ccammcjdkpgjmcpijpahlehmapgmphmk)로 SWEA와 프로그래머스 풀이가,
코드트리의 GitHub 연동으로 [코드트리](https://www.codetree.ai/ko) 풀이가 자동 업로드됩니다.

## 📁 폴더 구조

SWEA와 프로그래머스는 백준허브 규칙에 따라 **플랫폼 → 난이도 → 문제** 순으로,
코드트리는 연동 규칙에 따라 **트레일 → 문제** 순으로 정리됩니다.

```
Algorithm/
├── README.md                        # 현재 파일 — 저장소 안내 & 운영 규칙
├── 프로그래머스/
│   ├── 1/
│   │   └── 86491. 최소직사각형/
│   │       ├── README.md            # 지문(백준허브)
│   │       └── 문제이름.py            # Python 제출 코드
│   │
├── trail2/                          # 코드트리 Trail 2
│   └── 문제이름/
│       ├── README.md                # 문제 정보(코드트리 연동)
│       └── problem-slug.py          # 제출 코드
│
└── SWEA/
    ├── D2/
    │   └── 1234. 문제이름/
    │       ├── README.md            # 지문(백준허브)
    │       └── 문제이름.py            # Python 제출 코드
    ├── D3/
    ├── D4/
    ├── D5/
    ├── D6/
    └── Unrated/
```

- **난이도**는 폴더로 구분됩니다. (백준허브가 자동 생성)

## ⚙️ 저장소 운영 방식

- 🔵 **백준허브** (자동) — 문제 폴더 생성, 코드 업로드, 지문 README 생성, 커밋 & 푸시
- 🟢 **코드트리 연동** (자동) — 문제를 통과하면 트레일 폴더에 코드와 문제 정보 README를 커밋 & 푸시
- 🙋 **나** — 문제 풀기, **다시 풀어볼 문제 정리**

### 작업 흐름
1. 문제를 풀고 제출하면 → 백준허브나 코드트리 연동이 자동으로 폴더·코드·README를 커밋한다.
2. 나는 복습하고 싶은 문제를 위 **다시 풀어볼 문제** 목록에 추가한다.

> 💡 커밋 컨벤션: 코드트리는 `[Passed] 문제이름 (47ms, 16MB)` 형식으로, 백준허브는 `[D1] Title: ..., -BaekjoonHub` 형식으로 자동 커밋합니다.
