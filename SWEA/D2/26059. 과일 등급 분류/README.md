## 문제 요약
무게가 주어진 과일 N개를 무게 기준으로 **저·중·고 3등급**으로 나눈다. 각 등급의 개수는
모두 `[lo, hi]` 범위여야 하고, **무게가 같은 과일은 반드시 같은 등급**에 들어가야 한다.
가능한 분할 중 (등급별 개수의) `최대 − 최소`가 가장 작은 값을 구하고, 불가능하면 -1.

## 접근 방법
- 무게를 오름차순 정렬하면 각 등급은 정렬된 배열의 연속 구간이 된다.
  따라서 등급을 나누는 일은 **두 개의 절단 위치 k1, k2**를 고르는 문제로 바뀐다.
- 같은 무게는 쪼갤 수 없으므로, 절단은 `weights[i] != weights[i+1]` 인
  **경계에서만** 가능하다. 바깥 루프 `i`로 첫 번째 절단(k1), 안쪽 루프 `j`로
  두 번째 절단(k2) 후보를 그런 경계에서만 잡는다.
- 세 구간 크기 `low = k1`, `mid = k2 - k1`, `high = n - k2`를 구한 뒤,
  하나라도 `[lo, hi]`를 벗어나면 건너뛴다.
- 유효한 분할마다 `max - min`을 계산해 최솟값 `diff_min`을 갱신하고,
  끝까지 유효 분할이 없으면 -1을 출력한다.

## 복잡도
- 시간: O(N log N + N²) — 정렬 후 절단 위치 두 개를 이중 루프로 완전탐색.
- 공간: O(N) — 정렬된 무게 배열.
