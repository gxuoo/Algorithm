## 문제 요약
N×N 바둑판에서 돌(`o`)이 가로·세로·대각선 어느 방향으로든 **5개 연속**으로 놓였으면
YES, 아니면 NO를 출력한다.

## 접근 방법
- 모든 칸 `(i, j)`를 **시작점**으로 잡고, 8방향 각각에 대해 `dfs`로 같은 방향으로만
  계속 나아가며 연속된 `o`의 개수를 센다.
- `dfs`는 세 가지로 끝난다 — `count >= 5`면 전역 `isValid`를 True로 만들고 종료,
  판을 벗어나면 종료, 현재 칸이 `o`가 아니면 종료. 셋 다 아니면 `count += 1` 후
  `dir_vec`만큼 이동해 재귀한다.
- 종료 검사 순서가 중요하다. `count >= 5`를 **경계 검사보다 먼저** 하기 때문에,
  5번째 돌이 판 가장자리에 있어 다음 칸이 판 밖이어도 정상적으로 YES가 잡힌다.
- 방향 8개는 사실 절반이 중복이다. 한 줄은 양쪽 끝에서 각각 탐색되므로
  `(0,1), (1,0), (1,1), (1,-1)` 네 방향만 봐도 결과가 같고, 탐색량이 절반으로 준다.

## 복잡도
- 시간: O(N³) — 시작점 N²개 × 8방향 × 한 방향당 최대 N칸.
- 공간: O(N²) — 판 저장. 재귀 깊이는 최대 5로 상수.

## 알고리즘 유형
DFS, 완전탐색, 구현
