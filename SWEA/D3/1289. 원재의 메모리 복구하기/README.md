## 문제 요약
모두 0으로 초기화된 N칸 메모리를, **i번째부터 마지막까지 전부 뒤집는** 조작만으로
목표 비트열과 똑같이 만들 때 필요한 최소 조작 횟수를 구한다.

## 접근 방법
- 왼쪽 칸부터 차례로 확정해 나간다. 현재 상태와 목표가 처음 어긋나는 자리에서
  조작을 한 번 쓰면 그 뒤가 통째로 반전되므로, **어긋나는 자리마다 정확히 1회**가 필요하고
  그보다 적게 쓸 수는 없다.
- 어긋나는 자리는 결국 목표 문자열에서 **값이 바뀌는 경계**와 같다.
  따라서 `bits[i] != bits[i + 1]`인 지점의 개수를 세면 된다.
- 초기 상태가 전부 0이므로 첫 비트가 `'1'`이면 시작부터 어긋난 것 → `count`에 1을 먼저 더한다.
- 목표를 실제로 만들어 볼 필요 없이 문자열을 한 번 훑는 것으로 끝난다.

## 복잡도
- 시간: O(N) — 비트열을 한 번만 순회한다.
- 공간: O(N) — 입력 문자열. 추가로 쓰는 공간은 O(1).

## 알고리즘 유형
그리디, 문자열, 구현
