## 문제 요약
한 변이 N(홀수)인 정사각 농장에서, 가운데 행을 가장 넓은 줄로 하는 **마름모 영역**의
농작물 가치를 모두 더한다.

## 접근 방법
- 마름모는 행마다 "가운데를 중심으로 좌우 대칭인 연속 구간"이므로,
  **행별로 시작·끝 열만 계산해 그 구간을 더하면** 된다. 별도의 탐색이 필요 없다.
- 위쪽 절반 (`i = 0 ~ n // 2 - 1`) — 중앙 열 `n // 2`에서 좌우로 `i`칸씩 벌어진다.
  `j`가 `n // 2 - i` 부터 `n // 2 + i` 까지 → 폭이 1, 3, 5, … 로 늘어난다.
- 가운데 행부터 아래쪽 (`i = n // 2 ~ n - 1`) — 중앙 행에서 `i - n // 2`만큼 내려온 만큼
  양쪽에서 그 수만큼 좁아진다. `j`가 `i - n // 2` 부터 `n - (i - n // 2) - 1` 까지 →
  가운데 행에서 폭 `n`으로 시작해 마지막 행에서 폭 1이 된다.
- 두 루프의 경계에서 가운데 행이 겹치지 않도록, 위쪽 루프는 `n // 2` **직전까지만**
  돌고 가운데 행은 아래쪽 루프가 맡는다.

## 복잡도
- 시간: O(N²) — 마름모 칸 수는 약 N²/2 이고, 입력을 읽는 것부터 이미 O(N²).
- 공간: O(N²) — 농장 전체를 저장. 행을 읽는 즉시 더하면 O(N)까지 줄일 수 있다.
