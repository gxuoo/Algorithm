## 문제 요약
공은 `()`로 보이지만 잡초 `|`가 공의 한쪽을 가릴 수 있어 `(|` 나 `|)` 로도 나타난다.
주어진 문자열에 공이 몇 개 있는지 센다.

## 접근 방법
- 잡초에 가려진 공을 **먼저 원래 모양으로 되돌린 뒤** 세는 2패스 방식.
- 1패스 — 인접한 두 칸을 훑으며 잡초를 괄호로 복원한다.
  - `(` 다음이 `|` 면, 그 `|`는 가려진 오른쪽 절반이므로 `)` 로 바꾼다.
  - `|` 다음이 `)` 면, 그 `|`는 가려진 왼쪽 절반이므로 `(` 로 바꾼다.
  - 왼쪽에서 오른쪽으로 한 방향으로 훑으므로, 앞에서 `)`로 바뀐 칸이
    바로 다음 검사에서 다시 쓰이는 일은 없다.
- 2패스 — 복원된 문자열에서 `()` 가 인접해 나오는 횟수를 세면 그것이 공의 개수다.
- 한 칸에서 두 `if`를 순서대로 보므로, `(|)` 처럼 잡초 하나가 양쪽 괄호 사이에 낀 경우도
  첫 번째 규칙이 먼저 적용돼 `()` 하나로 정리된다.

## 복잡도
- 시간: O(N) — 문자열을 두 번 훑는다.
- 공간: O(N) — 문자 리스트.
